# Автосервис

## Описание проекта

**«Автосервис»** — настольное WPF-приложение для автоматизации работы автосервисного центра.

Программа предназначена для ведения учета клиентов, автомобилей и выполняемых ремонтных работ. Она позволяет упорядочить информацию, упростить работу сотрудников и обеспечить удобное хранение данных.

### Основные возможности

- Учет и просмотр информации о клиентах.
- Добавление и редактирование данных об автомобилях.
- Регистрация заявок на ремонт.
- Учет выполняемых ремонтных работ.
- Хранение информации в базе данных.
- Просмотр и управление записями.

## Используемые технологии

| Технология | Назначение |
|---|---|
| C# | Основной язык программирования |
| WPF | Разработка графического интерфейса |
| PostgreSQL | Хранение и управление данными |
| XAML | Создание пользовательского интерфейса |

## Требования

Для запуска приложения необходимы:

- Windows 10 или Windows 11.
- Установленный .NET SDK, совместимый с проектом.
- PostgreSQL.
- Visual Studio с поддержкой разработки WPF-приложений.

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone <ссылка-на-репозиторий>
   ```

2. Откройте решение проекта (`.sln`) в Visual Studio.

3. Установите и запустите PostgreSQL.

4. Создайте базу данных для приложения.

5. Настройте строку подключения к базе данных в конфигурации проекта.

6. Восстановите необходимые NuGet-пакеты.

7. Соберите и запустите проект, нажав `F5` в Visual Studio.

## Структура проекта

- `Models` — модели данных.
- `Views` — окна и элементы интерфейса.
- `ViewModels` — логика взаимодействия интерфейса с данными.
- `Data` — работа с базой данных.
- `Resources` — изображения, иконки и стили приложения.

*Структура может отличаться в зависимости от организации проекта.*
